# 📚 BCB (Bibliothèque Centrale Béjaia)

BCB est une application de gestion de bibliothèque universitaire conçue pour faciliter l'administration des ouvrages, des abonnés et des bibliothécaires. Elle offre une interface intuitive permettant une gestion efficace des emprunts et des retours, ainsi que des fonctionnalités avancées pour le suivi des activités de la bibliothèque.

## ✨ Fonctionnalités

- **Gestion des abonnés** : Ajout, modification et suppression des abonnés.
- **Gestion des bibliothécaires** : Création et gestion des comptes avec rôles spécifiques.
- **Gestion des ouvrages** : Ajout, modification, suppression et recherche d'ouvrages.
- **Emprunts et retours** : Suivi des prêts et des restitutions d'ouvrages.
- **Authentification et autorisation** : Connexion sécurisée avec gestion des rôles.
- **Tableaux de bord** : Statistiques sur les emprunts, retours et disponibilité des ouvrages.

## 🚀 Installation

### 1. Cloner le dépôt
```bash
git clone https://github.com/Adelbenyoub99/bibliothequeuniv.git
cd bibliothequeuniv
```

### 2. Installation des dépendances
```bash
npm install
```

### 3. Démarrer l'application
```bash
npm start
```

### 4. Accéder à l'application
Ouvrez votre navigateur et allez à : [http://localhost:3000].
